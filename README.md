# Image Hover Animation (Squeeze + Orbit rotation)
The goal is to create a smooth and visually appealing effect where the image slightly moves in a circular motion and performs a squeeze animation at the start.

# Features

## Hover-Based Animation
*  animation runs by default

## Squeeze Effect
* Image compresses and stretches at the beginning
* Creates a dynamic and engaging feel

## Micro Circular Movement
* Image moves slightly in different directions
* Gives a subtle circular/wobble effect
* Keeps the image in the same position

# Technologies Used
* HTML5
* CSS3
* CSS Keyframes Animation
* Transform (scale & translate)
